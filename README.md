# Дорога к Судному дню

Хронология Marvel по датам премьер — что посмотреть перед «Мстители: Судный день» (18 декабря 2026).
Сайт: https://emilsvifullin.github.io/it-all-leads-to-doom/

- **Навигация:** липкая панель с поиском (`/`), быстрый выбор «Всё / Важное / Обязательное», прыжок к году,
  кнопка «Дальше» (клавиша `n`) к следующему непросмотренному, сворачиваемые годы.
- **Скрытие:** уровень «Важное» убирает пункты «по желанию», «Обязательное» оставляет только главное;
  любой пункт можно скрыть кнопкой-глазом. Фильтры по франшизам, компактный вид.
- **Оценки героями:** 10 пауков, щитов, молотов, шлемов Дума… вместо цифр, с подписями-приколами.
- **Синхронизация:** без регистрации. У каждой коллекции 20-символьный код; на другом устройстве
  «Синхр.» → QR-код или ввод кода. Изменения приходят мгновенно (Supabase RPC + Realtime Broadcast),
  офлайн всё сохраняется локально и отправляется позже.
- **PWA:** «На экран Домой» на iPhone/iPad или установка в Chrome/Edge; работает без сети.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка |
| `styles.css` | дизайн и адаптивная вёрстка (телефон / планшет / десктоп) |
| `app.js` | логика: фильтры, оценки, синхронизация, заставка |
| `data.js` | список фильмов и сериалов |
| `icons.js` | SVG-иконки героев для оценок |
| `sw.js` | service worker для офлайна |
| `supabase/doom_sync.sql` | схема и функция синхронизации (Supabase-проект padel-id, схема `doom`) |

Локально: `python3 -m http.server` в папке проекта.
